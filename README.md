# 제주민원메이트 (Jeju Minwon Mate)

> **소상공인·도민 생활·영업 피해 행정 민원 작성 및 법규·관할 연계 보조 풀스택 웹 애플리케이션**

제주 소상공인과 도민이 일상에서 겪는 축사 악취, 불법 주정차, 쓰레기 무단투기, 도로 파손, 소음 등의 피해를 대화, 구어체 텍스트, 음성, 현장 사진으로 입력하면 **① 상황 구조화(6W) → ② 기상·시설·제주 조례 근거 매칭 → ③ 제주도 3계층 관할 부서 및 접수 채널 안내 → ④ 수정 가능한 민원서와 후속 대응 가이드 생성**까지 전 과정을 원스톱으로 지원합니다.

---

## 1. 주요 특징 및 가치

1. **상황 구조화 (STEP 1)**
   - 대화형 AI 상담관 또는 직접 입력 / 시연 프리셋 (2종)
   - 음성 녹음(MediaRecorder) 및 전사문 직접 검토·수정
   - 현장 입증 사진 미리보기 및 동의 기반 전송 (사진만으로 악취·위법성을 단정하지 않는 원칙 준수)
   - 제주 행정구역(제주시 26개, 서귀포시 17개 읍·면·동) 및 GPS 경계 기반 추천

2. **근거 매칭 (STEP 2)**
   - **Open-Meteo Forecast API**: 기온, 풍향, 풍속, 습도 등 수치예보 모델 연동
   - **공공시설 공간정보**: 단속 CCTV, 클린하우스, 어린이보호구역, 빗물받이 거리·반경 매칭
   - **제주특별자치도 자치법규(ELIS)**: 16대 생활분야 조례 카탈로그 중 최대 3건 검증 근거 제시

3. **3계층 관할 추천 (STEP 3)**
   - **제주도 본청** (총괄 정책) / **행정시** (지도·점검·단속 집행) / **읍·면·동 주민센터** (초동 접수)
   - **복합 민원 분리**: 주정차와 폐기물이 결합된 민원을 별도 사안(Issue 1, Issue 2)으로 자동 분리
   - 공식 접수 채널: 국민신문고, 안전신문고, 제주도청 민원안내 직링크 및 사전 체크리스트

4. **민원서 초안과 후속 대응 (STEP 4)**
   - 수정 가능한 공식 행정 민원 서식
   - **표현 순화 대조표**: 감정적 비난을 정중한 공식 행정 요청문으로 순화 (피해 사실은 축소하지 않음)
   - **4대 편의 기능**: 전체 복사, `.txt` 파일 다운로드, 인쇄(@media print 전용 서식), 이력 저장
   - **후속 가이드**: 법정 답변 기한(7~14일) 및 '단순 계도'에 그쳤을 때 보완할 증빙 팁 3가지

5. **부가 기능 (3종)**
   - **동네별 민원 통계 (`/stats`)**: 초기 8건 + 사용자 저장 건 합산, 4개 KPI, 읍·면·동별 반복 유형 막대 차트, 정책 검토용 브리프
   - **민원 이력 (`/history`)**: 검색, 상세 전문 보기, 복사, 사용자 작성 건 삭제 (통계 즉시 재계산)
   - **조례·법령 검색 (`/ordinances`)**: 16개 생활분야 다중 검색, 추천 키워드 10종, 3계층 관할 매핑표, '민원 작성에 인용하기' 원클릭 연동

## 2. 기술 스택 및 아키텍처

- **Frontend**: React 18, TypeScript, Vite 6, Tailwind CSS v4, Lucide React, React Router v6
- **Backend**: Node.js v26, Express, `@google/genai` (Gemini SDK), Open-Meteo API
- **Contracts**: 공유 Zod 스키마 (`src/shared/schemas.ts`)
- **Testing**: Vitest (12개 단위/계약 테스트 통과)

## 3. 실행 방법

### 환경 준비
```bash
# 의존성 설치
npm install
```

### 환경변수 설정 (`.env`)
`.env.example`을 복사하여 `.env`를 생성합니다:
```bash
cp .env.example .env
```

```env
PORT=3000
APP_MODE=demo
GEMINI_API_KEY=
GEMINI_TEXT_MODEL=gemini-4-hydrogen
GEMINI_TRANSCRIBE_MODEL=gemini-3.5-transcribe
```

### 실행 명령어
```bash
# 개발 서버 실행 (Express + Vite 미들웨어)
npm run dev

# 타입스크립트 검사 (클라이언트 + 서버)
npm run typecheck

# 단위 및 계약 테스트 실행
npm test

# 프로덕션 빌드 (Vite 클라이언트 번들 + 서버 컴파일)
npm run build

# 프로덕션 서버 실행
npm start
```

## 4. 모드(APP_MODE) 차이 및 연동 정책

| 구분 | 시연 모드 (`APP_MODE=demo`) | 실연동 모드 (`APP_MODE=live`) |
| :--- | :--- | :--- |
| **API 키 필요 여부** | 불필요 (키 없이 4단계 전 과정 완결) | `GEMINI_API_KEY` 필수 |
| **상황 구조화 & 챗봇** | 2개 프리셋 및 결정론적 고품질 응답 | Gemini 4 Hydrogen 실시간 모델 호출 |
| **음성 전사** | 음성 인식 시연 전사 텍스트 반환 | `gemini-3.5-transcribe` Interactions API |
| **기상 데이터** | 모델 기반 시연 기상 수치 제공 | Open-Meteo 실시간 기상 관측 모델 호출 |
| **실패 처리** | 완결된 시연 데이터 보장 | 실패 원인(키/권한/네트워크)을 명시적으로 안내 (조용히 시연으로 대체하지 않음) |

## 6. 법적 고지 및 면책

본 서비스는 민원 작성·접수 보조 도구입니다. 공식 기관 로그인, 실제 민원 제출, 기관 답변 추적을 대행하지 않으며 행정 처리 결과를 보장하지 않습니다. 공식 제출은 검증된 정부 공식 채널(국민신문고·안전신문고)을 이용하시기 바랍니다.
